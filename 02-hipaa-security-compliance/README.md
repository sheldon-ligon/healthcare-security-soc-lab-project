
# Week 2 – HIPAA Security and Compliance

## Objective
Evaluate how the proposed physician's office network architecture supports the protection of electronic protected health information (ePHI) under HIPAA, HITECH, and the HIPAA Omnibus Rule.

## Environment
The proposed network architecture includes:
- High-availability firewalls (FW-01 and FW-02)
- Segmented networks for administrative, clinical, server, guest, and security monitoring systems
- Oracle database for patient records
- Remote-access VPN with multifactor authentication (MFA)
- Centralized security monitoring through SIEM-01
- Local and encrypted cloud backups

## Security and Compliance Requirements
The Week 2 assessment focuses on five areas:

1. HIPAA-compliant network design
2. Patient data segregation and protection
3. Secure remote access for healthcare providers
4. Audit logging and security monitoring
5. Incident response and disaster recovery planning
